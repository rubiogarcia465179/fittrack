# Ejemplos de estilo para generar dibujos

Los dibujos reales de **Everkinetic** que usa FitTrack, en negro sobre blanco
(512 px), para adjuntarlos como **ejemplos de estilo** al generar los dibujos
que faltan (`docs/fotos/PROMPTS-DIBUJOS.md`). Nombre = `<id del ejercicio>-1`
(posición inicial) o `-2` (final).

(fondo blanco, recorte, tamaño). Originales y cambios: `docs/CREDITOS-DIBUJOS.md`.
